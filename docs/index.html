HOW IT WORKS

Your local state, made portable.

A deterministic handoff flow designed to preserve signal—not recreate a chat transcript.

  1. 01 ⌕

    Detect session

    Find the newest matching local coding-session log for your project.

  2. 02 ⇢

    Extract deterministically

    Read useful text and Git state with local parsing—never an LLM call.

  3. 03 ▤

    Render handoff.md

    Package the goal, decisions, files, state, errors, and next step compactly.

  4. 04 ↗

    Paste and continue

    Start the next AI account with the context it needs to keep moving.

⌁
No LLM calls. No API key. No chat upload.

Your session logs stay on your machine; only the handoff you choose to paste leaves it.

LOCAL ONLY

COMMAND REFERENCE

Small command surface. Useful handoffs.

Everything you need is built into the local CLI.

CommandFlagsWhat it does
context-passport export --tool <codex|claude|cursor> Detects the newest matching local session log, extracts context, and writes handoff.md.
context-passport show --clipboard Prints handoff.md, or copies it to the clipboard.
context-passport inject — Inserts the handoff into AGENTS.md, preferring it over CLAUDE.md; re-runs replace the old block.
context-passport watch --interval <minutes>
--tool <name>		 Refreshes handoff.md on a timer; the default is every 10 minutes.

On a phone, swipe the command table to see every flag and description →

--tool also works before export: context-passport --tool codex export

QUICK START

From zero to a handoff in three commands.

Clone the project, install dependencies, and generate your first local handoff.

  1. 1

    Clone the repository

    git clone https://github.com/chetanpujari5105/Context-Passport.git cd Context-Passport
  2. 2

    Install dependencies

    npm install
  3. 3

    Export your handoff

    node bin/cli.js export
