01 / THE PROBLEM

A transcript is not a handoff.

When an AI account hits a rate limit, changing to another account often means pasting a huge chat history and retelling the same project story.

WithoutManual re-explanation

“I’m working on a CLI in a new repo. Here’s what we discussed, the files I changed, the error output, and the decisions we made…”

A sprawling context paste, recreated from memory.

# Context Passport Handoff

Goal Build a local CLI that creates compact coding-session handoffs.

Next step Run the tests and paste this into the new session.

The signal the next session actually needs.

02 / THE FLOW

Make local progress portable.

It reads the useful state, shapes it compactly, and leaves you with a file you control.

  1. 01

    Detect

    Find the newest matching local coding-session log for your project.

  2. 02

    Extract

    Read useful text and Git state with deterministic local parsing.

  3. 03

    Shape

    Render the goal, decisions, files, state, errors, and next step into handoff.md.

  4. 04

    Continue

    Paste the compact handoff into the next account and carry on.

Zero cost. Zero privacy risk. Fully offline after install.

Nothing leaves your machine until you choose to paste it.

03 / COMMAND REFERENCE

Four commands.
One clean exit.

A small command surface for getting your context out of one session and into the next.

context-passportCLI reference
01
context-passport export

--tool <codex|claude|cursor>

Detect the newest matching session, extract context, and write handoff.md.

02
context-passport show

--clipboard

Print handoff.md, or copy it to your clipboard.

03
context-passport inject

—

Insert the handoff into AGENTS.md; later runs replace the existing block.

04
context-passport watch

--interval <minutes> · --tool <name>

Refresh handoff.md on a timer; the default is every 10 minutes.

--tool also works before export: context-passport --tool codex export

04 / QUICK START

From zero to a handoff in three moves.

Clone it, install dependencies, then export the session context in your local checkout.

Read the source on GitHub ↗
  1. 01

    Clone

    Get the project locally.

    git clone https://github.com/chetanpujari5105/Context-Passport.git cd Context-Passport
  2. 02

    Install

    Install the project dependencies.

    npm install
  3. 03

    Export

    Write your compact handoff.

    node bin/cli.js export
